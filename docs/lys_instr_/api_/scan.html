Scan

class lys_instr.gui.MultiScan.ScanWidget(storage, motors, switches, detectors)[source]

Bases: QWidget

Scan configuration and execution panel.

Provides a list-based GUI for composing a sequence of motor and switch scans, configuring detector/process settings, and starting/stopping scan execution. The scan can also be configured and executed programmatically (see setScanList(), start() and waitForFinished()), and the GUI follows the changes.

setScanList(rows)[source]

Set the scan list.

Each row is a dict with the following keys:

  • name (str): Axis name. "loop" simply repeats the acquisition.

  • range: For motor axes, (from, step, numberOfSteps) in Linear mode or a comma-separated string of values in Free mode. For switch axes, omit it to iterate over all labels, or give a comma-separated string (or list) of labels.

  • mode (str, optional): "Linear" or "Free" for motor axes, "Iteration" or "Free" for switch axes. If omitted, a string range means Free mode and a sequence means Linear mode. Specify mode="Free" to give the values of a motor axis as a list.

  • type (str, optional): Ignored. Inferred from the axis.

Example:

scan.setScanList([{"name": "y", "range": (0, 1, 3)}, {"name": "x", "range": (0, 0.5, 5)}])
Parameters:

rows (list[dict]) – Scan rows from the outermost (Scan1) to the innermost.

Raises:

  • ValueError – If a row is invalid (e.g. unknown axis).

  • RuntimeError – If a scan is running.
